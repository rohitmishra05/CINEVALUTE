# CineVault

CineVault is your personal, unified cinema universe—a beautifully crafted, local-first web application designed to help you discover, track, and curate both **Movies** and **Web Series**.

## 🌟 Features

*   **Unified Tracking**: Seamlessly manage your watchlists, favorites, and currently watching content across both movies and TV shows/web series.
*   **Premium Design**: Features a modern, glassmorphic UI with smooth 60fps micro-animations and a deep, cinematic color palette (inspired by high-end streaming platforms).
*   **Smart Dashboard**: Instantly view your vault statistics, recently added items, and a dedicated **Starred Favorites** section for your highest-rated content.
*   **Random Picker**: Can't decide what to watch? Let the vault pick for you! Spin the random picker across all your content, or filter specifically by Movies or Web Series.
*   **Filmmaker Notes**: Add personal ratings (up to 10 stars) and detailed reviews based on Storytelling, Cinematography, Editing, and Acting.
*   **Local Privacy**: 100% privacy-focused. All your data is securely stored in your browser's local storage—no account required.
*   **Import / Export**: Easily backup your entire vault (movies and series) to a JSON file and restore it on any device.

## 🚀 Tech Stack

*   **Frontend**: Vanilla HTML5, CSS3 (with extensive use of CSS variables and modern Grid/Flexbox layouts), and ES6 JavaScript.
*   **Architecture**: Single Page Application (SPA) with a lightweight, dynamic routing system and module-based controllers.
*   **Data**: Powered by the **OMDb API** for rich movie and series metadata.
*   **Icons**: Phosphor Icons.

## 📦 Getting Started

To run the project locally, you don't need any build tools or dependencies!

1.  Clone this repository:
    ```bash
    git clone https://github.com/rohitmishra05/CINEVALUTE.git
    ```
2.  Open the project directory and serve the files. You can use any static server, for example with Python:
    ```bash
    python -m http.server 8000
    ```
3.  Open `http://localhost:8000` in your web browser.

## 💡 Usage

*   **Discover**: Search for any movie or web series using the OMDb API.
*   **Add to Vault**: Click "Add to Vault" to save an item to your local collections (Watchlist, Watched, etc.).
*   **Rate & Review**: Open an item's details to rate it and leave your own filmmaker notes.
*   **Collections**: Organize your vault manually or rely on the smart, dynamic Dashboard.
